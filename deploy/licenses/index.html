Source code

The FLAC and Opus decoder files on this site are the unmodified builds published on npm. Their source packages, including the LGPL-licensed codec-parser that the FLAC decoder contains, are available here:

  • codec-parser-2.5.0.tgz (LGPL-3.0-or-later)
  • wasm-audio-decoders-flac-0.2.11.tgz
  • wasm-audio-decoders-common-9.0.7.tgz
  • opus-decoder-0.7.12.tgz
  • SHA-256 checksums

The FLAC decoder is a separate file (/flac-decoder.min.js) that the app loads only when it needs it, so it can be replaced with a version built from modified source. The ALAC decoder's source is m4a-decoder.js itself.
